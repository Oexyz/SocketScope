# Inter font provenance

SocketScope embeds the unmodified upright Inter variable font supplied by the
repository owner. The source download contained the `opsz` and `wght` axes, static
variants, an italic variable font, the upstream README, and `OFL.txt`. SocketScope
packages only the upright variable font it uses and the matching license text.
