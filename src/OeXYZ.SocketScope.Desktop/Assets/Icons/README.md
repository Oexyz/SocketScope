# SocketScope icon

`socketscope.svg`, `socketscope.png`, and `socketscope.ico` are original OeXYZ
SocketScope project artwork. They are distributed under the repository MIT license.

The SVG is the editable source. The PNG and multi-size Windows ICO are generated by
`eng/New-AppIcon.ps1`; they do not contain third-party artwork or remotely loaded
content.
